# Pricing & Unit Economics

**Plan:** Indie — $29/month

## Per paying subscriber per month

```
┌─────────────────────────────────────────┬──────────────┐
│ Revenue                                 │ $29.00       │
├─────────────────────────────────────────┼──────────────┤
│ Paddle fee (5% + $0.50)                 │ −$1.95       │
├─────────────────────────────────────────┼──────────────┤
│ LLM — 25 runs × 95 prospects × $0.0016 │ −$3.80        │
├─────────────────────────────────────────┼──────────────┤
│ Infrastructure (est.)                   │ −$0.75       │
├─────────────────────────────────────────┼──────────────┤
│ Pre-tax profit                          │ $22.50 (78%) │
├─────────────────────────────────────────┼──────────────┤
│ Swedish corporate tax (20.6%)           │ −$4.64       │
├─────────────────────────────────────────┼──────────────┤
│ Post-corp-tax retained                  │ $17.86 (62%) │
└─────────────────────────────────────────┴──────────────┘
```

Extraction (salary/dividend) reduces take-home further depending on setup.

## Trial cost amortization (one-time per acquired subscriber)

Trial: 3 days, ~3 runs × 95 prospects × $0.0016 = **$0.46/trial user**

| Conversion rate | Trial cost per paying customer |
|---|---|
| 30% | $1.53 |
| 20% | $2.30 |
| 10% | $4.60 |

Recovered within the first paid month at any conversion rate.

## Notes

- LLM cost assumes worst-case (25 runs/month, 95 prospects/run, all LLM-scored)
- Paddle acts as merchant of record — handles VAT globally
- Infrastructure estimate is per-subscriber share; revisit as user base grows
